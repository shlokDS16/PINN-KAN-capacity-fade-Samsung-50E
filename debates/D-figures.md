## 3. Interface and deviations (decisions for the lead)

1. **Missing run artefacts.** The run record of code/README.md does not contain `window.csv`, the stress-function envelopes, the residual map, the
   superposition table, the contrasts and reference files, the controls file and the H7 summary. Their formats are fixed by the demo runs and listed
   in `code/figures/README.md`. The run writer or the analysis step must produce them; until then the scripts stop with "MISSING INPUT".
2. **Estimand of Fig. 4.** Drawn from `contrasts_B.json` as the median of ln(comparator/A1) with the exact order-statistic interval, following
   TYPE1_SIGNFLIP.md (the sign-flip rule of PREREG_v2 9.3 failed its type-I check). If the freeze keeps a different rule, only the contrasts file changes.
3. **pp secondary axis** (PREREG section 14) is replaced by a right-hand column of mean paired pp differences with BCa intervals; an exact secondary axis does not exist.
4. **Blinding.** `Provenance.require_frozen` refuses every non-synthetic Samsung-derived figure or table until `runs/prereg/FROZEN` exists; Fig. 2 panels a-d use
   metadata only. No real Samsung, ISU or SNL test number is used anywhere in the demo runs.
5. **Tier source.** Tiers are read from the statistics step and never computed by a figure script; without `--contrasts`, Fig. 4 falls back to a descriptive version with no tiers.
6. **Hand-typed text.** Only arm definitions (`table2.CHANGES`, copied from PREREG_v2 7.1), arm display names and axis labels are typed; no number is typed into a figure or table.
7. **Fig. 7 claim.** Per PREREG section 13 the map is descriptive until the statistician sets the rank-correlation threshold.
