## 2. New findings

### N1. MAJOR. The pre-set success condition is probably unreachable for both arms, by three independent mechanisms (prediction)
The judge states the contribution "can fail" (05 section 0). That is a feature. The issue is that the rule as built makes failure close to certain, so the freeze delay (1 to 1.5 days) and about 18 CPU-h (expected; ceiling 33) buy the fallback. The calibration is not run; each mechanism below is read from code.
- **(a) Temperature sign under laboratory aliasing.** From the identifier columns of the cell table (38 of the 40 pinned conditions present today): T = 35 C is INT in all 13 conditions, T = 45 C is HM in 12 and SIE in 3, T = 23 C is INT 6, SIE 3, HM 1. With one N(0, 0.15^2) offset per laboratory, a step between INT and HM conditions is a monotone temperature trend in the data. The sign label needs only 20 of 25 laws with the same sign, magnitude above 1 % of range, and additivity (`extraction_audit.py:236`); nothing in it knows about laboratories. T has the zero or the symmetric-quadratic truth in 12 of the 30 datasets (each input meets each stratum 6 times, rule 2.2), where any licensed sign is false (`false_statements`, `:359`), plus datasets where T is in an interaction. Three or more such datasets give k >= 3 and C1 fails (upper limit above 0.2 for k >= 3 at D = 30).
- **(b) Library-exact partial dependence licenses forms on out-of-library truths.** For a retained, additive input whose extracted edge is a single linear edge, `r_lin` is zero by construction and `r_log` exceeds 0.01 on any hull with a ratio above about 2 (the c_ch, dod, c_dch, soc_mid hulls: 5.5 to 7.4 % residual, my computation in 04). So the "form" licence is: retained, additive, the same extracted family in 20 of 25 laws. A hinge truth (convex, flat then rising) is typically extracted as a stable linear edge; the licence is then "form: linear" against a hinge truth, a false statement. Hinge and quadratic strata are 2 of 5 per input, so about two out-of-library inputs per dataset. The extraction-loss flag, the one quantity that reflects curvature, is excluded from the licence (m1).
- **(c) G15 cannot see interactions.** Scoring makes any form on an interacting input false (rule 4.1, `extraction_audit.py:357-358`); a G15 law is additive by construction, so the additivity test passes and the form is licensed whenever the input is retained and stable. Ten of 30 datasets carry an interaction between two inputs, with A_int on the same log-uniform range as the main effects. Three false datasets suffice to fail C1. The contribution needs C1 to C3 for **both** arms (`extraction_audit.py:421`, rule 4.2), so a G15 failure alone withdraws it. A15 h = 1 or h = 2 with a linear outer edge has the same blindness; only an A15 law with a log outer edge can show non-additivity.
- **What would show this prediction wrong.** A calibration in which hinge and quadratic inputs are mostly "not retained", "composed" or unlicensed, and T signs are mostly unlicensed under the alias, so that k <= 2 of 30 for both arms. The prediction cannot be tested before the freeze without breaking the rule that the calibration runs from the FROZEN commit.
- **Not a flaw in the rule's honesty**: a failed C1 prints no labels and the paper reverts to the fallback of judge section 5. It is a flaw in the expected value of the delay.

### N2. MAJOR. The laboratory map is an untracked, mutable, unpinned input of the only reproduction control
- `extraction_calibration.py:101-112` reads `data/processed/samsung_cells.csv`, which is gitignored (`.gitignore`: `data/processed/`), not in `PIN_FILES` (`guard.py:24`), and still being filled (38 of the 40 pinned training conditions have a row today; CHOICES 11 says two were missing). `lab_map_sha256` is written into `calibration.json` (`:301`) but compared with nothing at stats time (`require_calibration` does not read it).
- The bit-identical re-run (`rerun_check`, `:345-360`) re-reads the CSV. If the table changes between the calibration and the gate auditor's re-run (late cells, a regenerated file, a changed tie in a mixed-laboratory condition such as `T45|SOCmax0.8|DoD0.6|Cch1|Cdch2`, SIE 3 against HM 2), the re-run differs and "a mismatch voids the calibration" (rule 6). The control that replaced time ordering is then hostage to a file nobody pins. The same file also holds capacity-derived columns (`n_qc_pass`, `n_capacity_rows`, `last_elapsed_days`); the code reads seven identifier columns only, so there is no label channel, but the file is read as a whole.
- The map is built from every cycling row (type z), not from the cells kept after the inclusion and QC rules of PREREG 3.3; the real majority laboratory of a condition after exclusions can differ.

### N3. MAJOR. The content control does not detect omission or a hand-edited verdict
- `finalize` (`extraction_calibration.py:293-307`) scores whatever datasets are complete; D >= 22 is the only requirement (`extraction_audit.py:400-404`). Nothing requires the completed datasets to be the prefix 0..D-1 of the fixed order, nothing records the discarded ones, and `finalize` can be run any number of times (it overwrites `calibration.json`). Deleting the records of up to 8 of 30 datasets (the worst ones) before finalizing is undetectable: the hash-chosen re-run (`rerun_choice`, `:326-337`) re-runs three datasets that are present and compares them with the stored records.
- The stats step reads `cal["verdict"]` directly (`stats_v4.py` diff: `bool(v["arms"][arm]["C1"])`); `calibration.json` is never re-scored from `records_p*.jsonl` at stats time or by the re-run. A hand-edited verdict with the new file's hash as the pin passes `require_calibration`.
- Because the hash that chooses the re-run datasets is the hash of the finalized file, the operator can also repeat `finalize` (it contains `written_unix`, `:301`) to steer which three are re-run. Those three are genuine in any case, so the leverage is only on what is *not* checked.

### Minor new findings

- **n1. Resume after a torn write fails.** `run_cells` appends with `open(path, "a")` (`extraction_calibration.py:228-231`). A crash mid-line leaves a fragment without a newline; the next append lands on the same line and the merged line is unparseable. If more lines follow, `read_records` raises (`:200-204`: "unreadable line ... not the last line") on every later call and the run halts; if it is the last line, the new valid record is dropped silently and re-fitted. The rule says a torn last line is "tolerated on resume"; the code tolerates it at read time only. The laptop has crashed repeatedly (memory notes).
- **n2. Laboratory offsets are drawn over the fold's own laboratory set.** `lab_offsets(j, [labmap[k] for k in cyc])` (`:172`, `:115-119`) draws one value per *sorted laboratory present in that fold*. With the current map every fold has HM, INT and SIE (my computation), so the offsets are shared across folds as required. A fold lacking a laboratory (possible if the table completes differently, or with another m) would shift every later laboratory's offset and break "one truth shared by all folds". Latent, not triggered today.
- **n3. Wording that contradicts the M8 ruling.** `extraction_audit.json` `discussion_sentence` still reads "which of its effects the training design identifies" (v1 text); the audit now measures extraction behaviour, not the training design, and the judge restricted "identifiability" to the calibrated sense. In the failure branch `stability_table` prints raw extracted family counts per input (`extraction_audit.py:287-299`), the baseline's own information; the rows carry no licence word, but "linear: 25 of 25" will be read as one. The Results sentence counts signs "licensed without a form" in [s], so "the sign of [s]" omits the signs implied by the j form labels (reading 6).
- **n4. C3 and C2 are weaker than they look.** The baseline names a form whenever 20 of 25 extracted families agree (`baseline_labels`, `:364-377`), with no additivity or tie condition, and is scored against out-of-library and interacting truths; it fails C1 for the same reasons as N1(b)(c), so C3 passes almost for free and does not show that the tie rule, the additivity test or the gate (d) matter (when C1 passes, (d) is a no-op by construction). C2 is a point estimate on about 40 events (4 inputs x 12 linear/log strata minus interacting ones). Usefulness on the real law is not pre-set: an audit that licenses nothing on the Samsung cells still satisfies C1 to C3 and keeps the bullet. T is excluded from the recall events by rule.
- **n5. Identifier-level channels, none a label channel.** `global_hull` (`:70-76`) is the union of the five folds' training identifiers, which is all 40 conditions (my computation), so each fold's synthetic truth hull is defined with the identifiers of that fold's own held-out conditions. The lab map covers the held-out conditions too (looked up for training conditions only, `:169-172`). `fold_design` still takes the union of S2 test conditions as the storage set (`:152-153`). No capacity value, score or outer-fold label reaches the calibration. Stated for the record because the brief asked.
- **n6. Banned-phrase list.** Seven phrases (`extraction_audit.json`); the section 4 claims of 03 (recovered, discovered, shows, power law, threshold) are not in it, and a lowercase substring test (`banned_phrases_in`, `:65-69`) on "enforced" also hits "unenforced". The grep is owned by the gate auditor, so this is a gap in the tool, not a breach.
- **n7. CPU estimate is unmeasured for the sampled space.** The 43 s mean per fit is from D021 fits at default hyperparameters (A15 grid 5, G15 grid 10, `d021_cap_study.py:85`); the draws include A15 grid 12 with h = 2 and G15 grid up to 30 (`arms.py:76-79`). At twice the per-fit time the 36 CPU-h cap is reached after about 24 of 30 datasets, close to D_min = 22 (void below it).
- **n8. The bound is relative to an invented mixture.** 40 % of (dataset, input) truths are out-of-library, one third of datasets carry an interaction, amplitudes are log-uniform with median about 0.16 (below PREREG 13's 0.5), lab sd 0.15. "P(E_d) <= 0.2" is a statement about that mixture; for the real law it holds only to the extent the mixture is representative, and the paper's sentence must say so.

## 4. Answers to the brief's checklist

- **Always-abstain loophole.** Closed on synthetic data by C2 (recall floor). Reopened on the real law: no floor there (n4), T excluded from recall, and N1 predicts abstention or failure rather than licences.
- **C1-C3 computability.** All three are computable from the stored per-dataset results (`verdict`, `extraction_audit.py:392-424`). C3 is nearly automatic (n4). D = 30 allows at most 2 false datasets; at D = 22, 1.
- **Strata realism.** Lab aliasing is on the real map (good) with one offset size and cycling cells only (M3); stratum prevalence is arbitrary (n8); N1(a) follows from the aliasing and is a realistic failure the audit has no instrument for.
- **A15/G15 symmetry.** Same function, same strata, same D, same bound; behaviour differs for the additivity gate (M5, N1c).
- **Guard bypass.** Public label functions with `calibrated=True` default (M7a); verdict not recomputed and omission undetected (N3); unpinned lab CSV (N2).
- **Outer-test channel.** None at the label or score level. Identifier-only channels listed in n5. The lab CSV carries QC-derived columns that the code does not read.
