Reading depth for every row: **E1, bibliographic metadata only (Crossref), plus Exa abstracts where noted; nothing here is a reading of the paper body.** The only exceptions are rows flagged HAVE, whose depth is stated in their own note. Status of all rows: `indexed`.

## Method and limits (read first)

- **OpenAlex was not usable.** `https://api.openalex.org/sources?filter=issn:2352-152X&select=id` returns HTTP 429 with `Retry-After: 29786` (about 8.3 h): 'free daily budget shared by everyone on your network's IP address ... used up'. A free key needs the user's email and a click on an emailed link; I did not send the user's address to a third party. So **the OpenAlex source id was NOT looked up and no OpenAlex counts or OA locations are used.** The Semantic Scholar graph API also returned 429.
- **All citation counts are Crossref `is-referenced-by-count` as of 2026-11-06.** Crossref counts are usually lower than OpenAlex/Scopus/Google Scholar (Schuster 2015: 437 here, 455 on an Exa-served index), so cross-year rankings are indicative. Citations/year = count / max(0.5, years since Crossref `issued` date); the 0.5-year floor limits inflation for 2026 items. Some 2026 items carry 2027 issue dates; the floor handles them.
- **OA status = presence of a Creative Commons licence in the Crossref record.** Unpaywall/OpenAlex were not queried, so 'no OA licence' means unverified, not closed. 'Best URL' is the ScienceDirect article page built from the Crossref `resource.primary` PII; scripted ScienceDirect fetches return 403 for this project (refs/PAYWALLED_FOR_SHLOK.md), so Shlok saves PDFs in a browser.
- **Selection method.** Crossref `journals/2352-152X/works` with `query.title`/`query.bibliographic`, `sort=is-referenced-by-count` (year-sliced 2014-2026) and `sort=score` (rows=150), about 75 topic queries; pool of 2,973 unique JES records; title-keyword screening, then manual curation. Titles were screened, not abstracts, so a paper may be mis-bucketed. Crossref `query` is a loose relevance match, so mid-cited relevant papers can be missed.
- **Not searched:** other journals' papers that JES papers build on (IEEE TTE, Applied Energy, J. Power Sources); preprints; JES papers whose titles lack the screening keywords; papers in press without Crossref records. Completeness of this list is not evidence of novelty.
- **DOI check:** every DOI below was fetched from `https://api.crossref.org/works/<doi>` and returned HTTP 200 with the title shown (103 records, 0 failures). Side finding: 10.1016/j.est.2021.103803 (JES 48, 103803, the Muehlbauer et al. reference cited in our Samsung note) is titled 'Pareto-optimal power flow control in heterogeneous battery energy storage systems' (Muehlbauer, Rang, Palm, Bohlen, Danzer). `notes/papers/samsung50e_dataset_paper.md` says 'DOI verified'; worth confirming that this is the paper the dataset's supplement means by the semi-empirical model source.

Legend: **HAVE** = we already hold a note or full text in the project (kept, never dropped). The ledger tool `tools/ledger.py` does not exist in this project (tools/ holds only download scripts), so no ledger rows were written.
