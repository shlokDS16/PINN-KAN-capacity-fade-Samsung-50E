# 15 Liu Z. et al. 2025: Verhulst KAN-PINN (Energies)

## Citation
Zeye Liu, Songtao Ye (corr.), Feifei Cui, Yu Ma. "Physical Information-Guided Kolmogorov-Arnold Networks for Battery State of Health Estimation." Energies 2025, 18(22), 5865. doi:10.3390/en18225865. Published 7 Nov 2025 (CC BY). Faculty of Electronic and Information Engineering, Xi'an Jiaotong University, and Chang'an University, Xi'an, China.

## Reading depth
reading: full text (MDPI HTML via Exa fetch; saved as `ROOT/refs/md/15_liu2025_html.md`). Tables 1-8 and equations read; figure images NOT visible, figures described from captions and text only. Heading numbers below refer to the paper's sections.

## Problem and stated contribution
SOH estimation for Li-ion cells with a physics-informed network whose MLP is replaced by a KAN, with the Verhulst capacity-loss ODE as soft constraint. Claims (Sec. 1, Sec. 4.2, Sec. 5): higher accuracy than LSTM/BiLSTM/GRU/Transformer/PINN-Verhulst; identification of hidden degradation parameters (k, u_i, M); robustness on a second chemistry (XJTU). The paper cites Wei et al. 2025 (Expert Syst. Appl. 296, 128969, KAN + attention + PINN; its ref 26) only in the introduction as a KAN-for-SOH precedent, so the novelty claim is narrow.

## Data
- TRI/Severson dataset (Sec. 2, Table 1): 124 A123 APR18650M1A LFP/graphite cells, 1.1 Ah, 72 fast-charge protocols, 25 C chamber, 4C CC discharge, 150-2300 cycles, end at 80% SOH.
- Inputs (Sec. 2): discharge voltage (2.0-3.6 V) and temperature (26-42 C) each resampled to 1024 points, plus discharge time tau and normalised cycle index t -> 2050-dim vector. Min-max scaling. Only the discharge phase is used (justified by a pointer to Severson).
- Label: SOH = C_max / C_rated x 100% (Eq. 1), C_rated = 1.1 Ah; network predicts u = 1 - SOH.
- Samples are individual cycles, "randomly shuffled" as the last preprocessing step (Sec. 2). Split quoted as 41 train / 40 validation / 43 test cells (Sec. 4), "based on the criteria in Severson". The counts match Severson's train/secondary/primary-test sizes (my inference; the paper does not say which batch is which).
- Second dataset: XJTU (Wang et al. 2024) NCM 18650, Batches 1-4, split 8:1:1, seed 1234 (Sec. 4.5). Whether 8:1:1 is by cell or by cycle is not stated.

## Model
- KAN with B-spline branch plus SiLU shortcut branch (Sec. 3.2); final config from the grid: grid size 2, spline order 3 (Sec. 4.3). Hidden layers: Table 3 says 2 layers x 64 nodes; the text of Sec. 4.3 says 2 x 16 won. These contradict (see Weaknesses).
- Output: scalar u_hat. Physics: Verhulst ODE du/dt = k (u - u_i)(1 - (u - u_i)/(M - u_i)) (Eq. 2), enforced as a loss residual f = du_hat/dt - G (Eq. 7) with autodiff w.r.t. normalised cycle t; k, u_i, M are three global trainable scalars (not per cell, not functions of stress). Bounds: k>0, 20% <= M <= 100%, 0<u<M.
- Loss L = 1*Lu + 6*Lf + 16*Lft (Table 3), where Lft penalises df/dt (a smoothness term on the residual). Weights "tuned by grid search" (range not given).
- Training: Adam lr 1e-3, StepLR step 50,000 gamma 0.1 (so no decay inside 200 epochs), 200 epochs, batch 64, RTX 4090, one fixed seed 1234 (Sec. 4).
- Learned parameters reported: k = 0.003389, M = 0.956, u_i = 0.0167 (Sec. 4.2). Units of k are per normalised-cycle unit; no uncertainty, no check against the per-cell fitted Verhulst parameters.

## Tuning
Phased grid over grid size {2,3,5}, order {2,3,4}, layers {1,2,3}, nodes {16,32,64} (Sec. 4.3, Fig. 7, Table 6). Selection is read off "RMSPE on the test set" (Sec. 4.3 text; Table 6 reports both validation and test, and the 2x64 row is the best on test, 0.300, which is also the headline number). So the headline test number is the minimum over a 81-point grid evaluated on that test set. The 41/40/43 split gives a validation set that could have been used instead, and the paper does not say it was. Interpolation length (512/1024/2048) also chosen with test RMSPE (Table 2).

## Evaluation
- Split: by cell at the 41/40/43 level (assumed), but within a cell all cycles from the early to the late life are estimated from that cycle's own discharge curve, so this is within-cell-trajectory estimation on unseen cells, which is standard for SOH estimation. Seeds: 1. Statistical test: none. Intervals: none (Fig. 5 shows a regression 95% band, not a seed spread).
- Metrics: RMSPE (Eq. 12, labelled x100% but values like 0.300 are reported, so units are ambiguous), MAE in % of capacity loss, R2. The metric is computed on u (capacity loss), not on SOH, so relative errors are inflated at small u (early life); MAE of 0.0120 "%" at 90-100% SOH (Table 4) vs 1.342 % overall (Table 5) differ by two orders and are not reconcilable from the text (a units issue).
- Headline (Table 5/7): KAN-PINN test RMSPE 0.300, MAE 1.342 %, R2 0.814. KAN without physics 0.364 / 1.648 %; MLP-PINN 0.516 / 2.103 %. Baselines LSTM 0.463 / 2.320, BiLSTM 0.485 / 2.448, GRU 0.455 / 2.250, Transformer 0.450 / 2.366, PINN-Verhulst 0.448 / 2.153 (Table 7). PINN-Verhulst R2 0.493 (Sec. 4.4).
- Internal inconsistencies: KAN-PINN validation MAE is 1.523 in Table 5 and 1.380 in Table 7; Table 6 2x64 row repeats 1.523. Sec. 4.4 says "no data augmentation", Sec. 4.4 also speaks of the dataset "before data augmentation". Sec. 4.4 states baseline hyperparameters "kept consistent with KAN-PINN" (not separately tuned), while KAN-PINN got a hyperparameter grid: the comparison is unequal in tuning effort.
- XJTU (Table 8): test RMSPE 0.074 / 0.075 / 0.077 / 0.152, MAE 0.245 / 0.142 / 0.268 / 0.520 % for batches 1-4. Each batch trained and tested separately; no cross-batch or cross-chemistry transfer, so "generalisation across chemistries" (Abstract) is not tested; only that the same recipe works on another dataset.

## Ablations
Table 5: remove physics (KAN) and remove KAN (MLP-PINN); Table 2: input length; Table 6/Fig. 7: KAN size/grid/order; Table 4: SOH stage (80-90% vs 90-100%); no ablation on the loss weights (1, 6, 16), on the smoothness term Lft, on fixing vs learning k/M/u_i, on removing temperature or time input, and no multi-seed repeat.

## Hidden assumptions
1. One Verhulst curve with three global scalars describes all 124 cells and all 72 protocols; no stress dependence enters k even though the cells have very different charging protocols and temperatures.
2. The derivative ∂u/∂t is taken w.r.t. a normalised cycle index while the network also receives the full discharge curve; since the curve itself encodes SOH, the residual can be satisfied without learning degradation kinetics (the network can simply read capacity from the curve). The physics term is then a regulariser on the cycle input, not a constraint that identifies kinetics.
3. Random shuffling of cycles inside training is acceptable only because the test cells are disjoint (assumed).
4. The reported 95% band and R2 generalise although there is one seed and one split.

## Weaknesses a reviewer would hit
- Test-set tuning: headline cell selected as the best entry of the phased grid chosen by test RMSPE (Sec. 4.3) and the interpolation length by test RMSPE (Table 2).
- Single seed (1234), no intervals, no significance test; the margin over baselines (0.300 vs 0.448 RMSPE) is plausible but untested, and baselines inherit KAN-PINN's hyperparameters instead of their own tuning.
- Contradictions: 2x16 (text) vs 2x64 (Table 3 and Table 6 best row); validation MAE 1.523 vs 1.380; units of RMSPE/MAE (0.0120 % vs 1.342 %); input count (2050 stated) vs 1024+1024+2.
- "Identification of physical parameters" is asserted by quoting three numbers (k = 0.003389, M = 0.956, u_i = 0.0167); no confidence interval, no repeat-run stability, no comparison with the direct fit of the Verhulst curve to the measured capacity trajectories, and the numbers are not shown to be identifiable (k and M trade off along a trajectory that stops at 80% SOH, where u is only about 0.2 and M = 0.956 is an extrapolation by a factor of about 5).
- The claim that the model generalises "across battery chemistries" (Abstract, Sec. 4.5) is not tested: each XJTU batch is trained and tested separately with an 8:1:1 split of unknown unit.
- Novelty overlap with Wei et al. 2025 (KAN + attention + PINN) and with the PINN-Verhulst of Wen et al. 2023; the contribution is the combination.
- Only TRI discharge data; cycle-index input available at deployment is assumed, which makes the task closer to curve-fitting of a monotone trend than to field SOH estimation.

## Gaps and hooks for our paper
1. Stress-dependent rate law: make k a function of measured stress (temperature, C-rate, depth of discharge) through a KAN with interpretable 1-D splines, so the learned edge functions are the degradation laws; Liu et al. has k as one global scalar, so the space is empty here (concrete, testable on datasets with systematically varied stress, not TRI alone).
2. Identifiability test: refit Verhulst (k, u_i, M) per seed, per cell-subset and with the truncated horizon (data only to 90% SOH) and report the profile likelihood or bootstrap spread; Liu reports none. Pre-registered threshold: parameters recovered within a stated tolerance across 5 seeds.
3. Show the physics term is doing work: swap Lf for a wrong ODE (e.g., linear or sqrt-time law) and for shuffled stress labels; if the metric does not move (as in Deng et al. 2025, ref 8, where two different SEI laws reach similar error after joint training) the constraint is a regulariser, not a law.
4. Cell-disjoint multi-seed evaluation with intervals and validation-only tuning, with baselines tuned equally (the standard in our contract, Sec. 6).
5. Efficiency table (training time, inference time, model size) as Liu's Table 2 is a good format for a JES reader; reuse the idea.
