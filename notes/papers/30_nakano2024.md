## Problem and stated contribution
Estimate energy-capacity SOH of an EV battery from the raw signals of a single driving trip (speed, voltage, current, SOC) with a transformer encoder, plus two label-free pre-training tasks. Claims (Abstract, Sec. 6, Sec. 8): RMSE 1.17 (+-0.17) and MAE 0.72 (+-0.04) in the base setting; best baseline LSTM RMSE 1.80 (+-0.13), MAE 1.12 (+-0.05) (Sec. 6.1); "first transformer-based SOH model for EVs using real-world operation data" (Sec. 1); with SOH-ordinal-comparison pre-training, half the labels give nearly the same error as all labels.

## Data
- Three EVs of one mass-market model, Japan Automobile Research Institute, Aug 2011 - Jun 2014 with a gap Sep 2012 - Mar 2013 (Sec. 4). Six main test routes (three highway, three urban) plus "Others"; trips 10-90 min and 10-90 km kept; phases of several months to over two years per route set; CCCV fast or normal charging.
- Inputs C = 4 channels (speed, voltage, current, SOC; SOC logged each minute and linearly interpolated to 1 s), sequence length fixed to S = 1800 s (Sec. 3.3).
- Label (Sec. 3.1, 4.2): SOH = E_current / E_initial x 100%, energy capacity in kWh from reference performance tests (RPT: C/3 constant-current full discharge at 25 C on a chassis dynamometer) done about every six months. Trip labels are produced by linear interpolation in odometer mileage between the two nearest RPTs (Eq. 8). So every trip label is a smooth function of mileage, not a measurement.
- Number of trips: appears in Table A.3 (not in the extracted text); not quoted here.
- Data: "confidential" (Data availability).

## Model
Conv input-embedding (L = 2 blocks, k1 = 4, k = 3, s1 = 2, s = 2, d = 256), learnable CLS token and positional encoding, N = 4 pre-norm transformer blocks with H = 16 heads, DropPath 0.1, attention dropout 0.1, FFN 4d, MLP head of d/2 (Sec. 3.2). MSE loss, AdamW, 300 epochs, lr 5e-5 then 1e-5 after epoch 150, gradient clip 10, random cropping (min ratio 0.9) and random contiguous key masking (10-30%) as augmentation (Sec. 3.3). Pre-training (Sec. 3.4): masked token prediction (50% of tokens, MSE) and SOH ordinal comparison (Siamese pair from the same EV; target = whether trip 1 has lower mileage than trip 2; BCE; 5 epochs). Physics: none. Table A.5 (read) gives SOH-TEC batch 32, clip 10, crop range (1620,1800), lr 5e-5 with decay at epoch 150 by factor 0.2, matching Sec. 3.3; baselines have their own searched settings.

## Tuning
Random search with Hyperband early stopping (max 200 epochs) on training and validation sets for the transformer and the MLP/CNN/LSTM baselines (Appendix A.4); the tree and linear models are listed with the feature set (statistics, IC, etc.). So each model family is tuned, which is better than Liu 2025 (ref 15). Test data are not used for early stopping: the best checkpoint is picked by validation loss and evaluated once (Sec. 5).

## Evaluation
- Split (Sec. 5): random 8:1:1 train/validation/test over trips, one fixed split throughout. Trips from the same vehicle, route and day appear in training and test. Eight random seeds for deep models and tree models (Exp. 1-3); ablations over five seeds with 95% CIs (Fig. 13).
- Baselines: dummy, route-aware dummy, MLP, CNN, LSTM, linear, ridge, random forest, LightGBM (Sec. 5). Recent SOH models were not run because they were built for lab charging data (Sec. 5).
- Exp. 1 (full trips): SOH-TEC RMSE 1.17 (+-0.17), MAE 0.72 (+-0.04); LSTM RMSE 1.80 (+-0.13), MAE 1.12 (+-0.05). Exp. 2 (urban segments only): LSTM's RMSE and MAE rise by 0.33 and 0.14, SOH-TEC's by 0.13 and 0.05 (Sec. 6.2). Exp. 3: alpha = 0.1 labels: ordinal pre-training improves RMSE by 36.4% and MAE by 47.8% relative to no pre-training; alpha = 0.5 pre-trained model RMSE 1.243 (+-0.14), MAE 0.716 (+-0.05) vs 1.167 (+-0.17) and 0.719 (+-0.04) with all labels (Sec. 6.3).
- Statistical test: none; error bars are seed standard deviations of a fixed split, so they exclude split variance.
- A "3% error margin" band is used on scatter plots as the visible tolerance.

## Ablations
Hyperparameter sweeps: N, d, k1, H, drop-path (Fig. 13); augmentation ratios (Fig. 14a); with/without speed input (Fig. 14b); pre-training tasks alone and combined (Exp. 3). Result as stated: even the worst hyperparameter setting beats all baselines (Sec. 7.2).

## Hidden assumptions
1. SOH of a trip equals linear interpolation in odometer between six-monthly RPTs; actual degradation includes calendar ageing and phases with different routes, so labels are smooth surrogates (acknowledged in Sec. 7.3).
2. Random splitting by trip is a fair test; trips from the same day or route are near-duplicates with almost identical labels.
3. Route and season are not confounders of SOH: Highway 2 and Urban 2 were driven only near the end of the collection, which the authors admit may create unintended associations (Sec. 7.3).
4. Three vehicles represent EV ageing.

## Weaknesses a reviewer would hit
- Leakage by design: random 8:1:1 split of trips from only three vehicles, with labels interpolated in mileage; a model that infers mileage proxies (route, ambient conditions, voltage level at a given SOC) can reach low error without learning degradation. No vehicle-held-out test, which the authors do not run (Sec. 7.3-7.4 call for more routes and vehicle types).
- Labels are interpolated, not measured per trip; the achievable error is bounded by interpolation error, which is never quantified.
- Data confidential and code on request; no external reproducibility.
- Only generic baselines; no recent SOH architecture is reproduced, so "outperforms the state of the art" is limited to the nine baselines.
- Pre-training result uses a randomly selected unlabelled subset of the same small dataset (Sec. 7.4); not a real unlabelled-fleet scenario.
- Seeds vary initialisation only.

## Gaps and hooks for our paper
1. Label-construction lesson: a stress-dependent degradation law can be trained from sparse reference tests only if the evaluation does not reward interpolation along time; use held-out cells/vehicles and report an "interpolation-only" baseline (mileage-linear predictor) as the floor that every model must beat; Nakano never reports this floor.
2. Monotonic ordinal pre-training is a physics-free prior that coincides with the monotone-degradation constraint; test whether a monotonicity constraint on the learned KAN rate (non-negative edge splines) gives the same label efficiency, and compare with the pairwise ordinal loss (a cheap, defensible comparator).
3. Figure form to adopt: parity scatter coloured by a nuisance factor (here route, ours stress condition) with a tolerance band and error insets (Figs 7, 9); label-efficiency curve (Fig. 11); CI-shaded ablation panels (Fig. 13).
4. Table of dataset descriptors by condition (Fig. 4 form) for our stress matrix.
