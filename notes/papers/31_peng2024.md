## Problem and stated contribution
SOH from partial-charge incremental-capacity (IC) features plus equivalent-circuit resistances, with KAN layers inside LSTM or TCN. Claims: first use of KAN for Li-ion SOH (Sec. 1, self-described), KAN hybrids beat BP/LSTM/TCN, LSTM-KAN best with MAE 0.412 % (test) and 0.256 % (validation), resistance inputs improve accuracy, no full charge/discharge needed (Abstract, Sec. 5). This is not physics-informed learning: physics enters only through the 2RC model used as a feature extractor.

## Data
- Own accelerated aging test (Sec. 2.1, Table 1): 8 commercial LiFePO4 cells, 20 Ah, 3.2 V nominal, 35 C, CC 1C - CV to C/20 - 1C discharge, 0.5 h rest; HPPC pulse sequence inserted in every discharge cycle. Neware BTS4000, 1 s sampling.
- Starting states are mixed (Table 2): Bat 1-4 fresh (100%) and Bat 5-8 pre-aged (90.3, 87.9, 88.09, 96.18% initial SOH); cycles experienced 500, 1070, 930, 380, 550, 375, 320, 590. So the corpus is 8 cells, fewer than 1100 cycles each.
- Features (Sec. 2.2): dQ/dV on a 1 mV grid with Gaussian smoothing; 15 features = position, height, width of three peaks plus position and height of three dips, all within 3.2-3.5 V (SOC about 20-85%). 2RC parameters R0, R1, R2, C1, C2 from recursive least squares on HPPC data at a fixed SOC (terminal-voltage MAE < 0.4 mV, Fig. 7).
- Label: SOH as maximum capacity over rated capacity (Sec. 1, stated; rated = 20 Ah).
- Input count is inconsistent: "18 parameters, 15 IC + 5 ECM" (Sec. 3.2) vs 20 in Table 4.

## Model
LSTM with its fully connected hidden layer replaced by a KAN layer (LSTM-KAN) and the same for TCN (TCN-KAN) (Sec. 3.1-3.2). The text gives the KAN formulas (Kolmogorov-Arnold theorem, layer as a matrix of 1-D functions) but no grid size, spline order, widths, optimiser, learning rate, epochs, window length or seed anywhere. KAN variant: not stated (presumably B-spline as in the original KAN, ref 15 of the paper).

## Tuning
Not described. No validation protocol, no hyperparameter search reported, so whether test data influenced choices cannot be checked.

## Evaluation
- Split (Sec. 4.1): train on Bat 1, 2, 3, 6, 7, 8; test Bat 4; validation Bat 5. The same paragraph first says "Bat. 4 and Bat. 8" are test and validation, then uses Bat 5 as validation in Figs 11, 13, 14 while Bat 8 is also in the training list. Cell-level split, but a single test cell and a single validation cell; the test cell is a fresh cell with the shortest-lived history (380 cycles) while the training pool includes the longer-lived fresh cells.
- Metrics: MAE, MAPE, RMSE (Eqs 20-22; the third is mislabelled "Mean Absolute Error (RMSE)").
- Table 3 (MAE / MAPE / RMSE, %). Test: BP 0.811/0.921/1.028; TCN 0.472/0.528/0.607; LSTM 0.519/0.585/0.641; LSTM-KAN 0.412/0.462/0.570; TCN-KAN 0.426/0.476/0.572. Validation: BP 0.531/0.569/0.727; TCN 0.461/0.495/0.547; LSTM 0.438/0.472/0.490; LSTM-KAN 0.256/0.278/0.378; TCN-KAN 0.251/0.268/0.365.
- On validation TCN-KAN is slightly better than LSTM-KAN (MAE 0.251 vs 0.256) but the text calls LSTM-KAN "best"; the differences between the two hybrids (0.005 and 0.014 points) are not tested.
- Seeds: not reported (single run implied). Statistical test: none. Baselines are MLP-family only (no GPR/XGBoost/CNN, no PINN, no plain KAN alone).
- Literature comparison (Sec. 4.1): "MAE 1.16 / 1.957 %" of two BP papers vs 0.412 %: different cells, features and splits, so not a controlled comparison.

## Ablations
Only the input ablation (IC only vs IC + resistance, Table 4, Figs 13-14) and the "with/without KAN" pairs in Table 3 (LSTM vs LSTM-KAN, TCN vs TCN-KAN). No ablation of KAN grid or order, of feature groups, of window length, or of the Gaussian filter.

## Hidden assumptions
1. HPPC-derived resistances at a fixed SOC and temperature are available in the field; this needs a pulse test or a rest-capable BMS.
2. The cells all ran the same 1C/35 C protocol, so the model never sees a change in stress; IC peaks shift with temperature and rate (the paper itself says so in Sec. 1) and none of that variation is in the data.
3. A model trained on 6 cells at one protocol generalises to other cells from the same lot; the test and validation cells come from the same batch of cells, bench and protocol.
4. Capacity ratio against 20 Ah rated capacity is the SOH, even for pre-aged cells starting at 88-96%.

## Weaknesses a reviewer would hit
- Eight cells, one chemistry, one protocol, one temperature; one test cell and one validation cell; no seeds, no interval, no significance test, so the 0.412 vs 0.519 % gap (LSTM-KAN vs LSTM, test) cannot be read as an effect of KAN.
- Missing KAN configuration and tuning details; non-reproducible; no code, no data on request only.
- Inconsistent split description (Bat 8 vs Bat 5) and input count (18 vs 20).
- Only MLP-family baselines; no GPR/XGBoost on the same IC features, which are usually the strong baselines for IC-feature SOH.
- Literature MAE comparison with 1.16 and 1.957 % is uncontrolled.
- No physics-informed component in the sense of our paper: the ECM is a feature extractor.
- Resistance features need HPPC pulses in every cycle, which are not part of a normal charge, contrary to the "no full charge/discharge needed" convenience claim.

## Gaps and hooks for our paper
1. A fair KAN-vs-MLP test on IC/ICA features with a nested, cell-grouped CV, 5+ seeds, and MLP/GPR/XGBoost baselines of matched parameter budget; Peng's gap of 0.1 points would need to survive this.
2. Stress as an input: the corpus here has no stress variation; our design with controlled temperature/C-rate/DoD varied across cells can show whether KAN splines on stress channels recover monotone, interpretable laws, where Peng only shows end accuracy.
3. Use the 1-D spline functions of the KAN as the figure: plot the learned edge function of peak position/height vs SOH (Peng never shows the splines; Liu 2025, ref 15, doesn't either).
4. Resistance as a physics-grounded channel: test whether ohmic resistance growth (R0 vs cycle) obeys the same law as capacity loss under stress, via a two-output PI-KAN, and test identifiability of the coupling parameter.
5. Figure form worth borrowing: the cycle-coloured IC stack (Fig. 4) with feature definitions (Fig. 5).
