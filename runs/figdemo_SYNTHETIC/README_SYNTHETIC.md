# SYNTHETIC DEMO RUNS - NOT RESULTS

Every number in this directory is drawn from an invented ageing law by `code/figures/make_demo_runs.py`.  Design identifiers (condition keys, cell ids, labs, stages) come from the dataset metadata and the preregistered split file; no Samsung, ISU or SNL retention value, model fit or test score is used.  Figures built from this directory carry the watermark 'SYNTHETIC DEMO - NOT RESULTS' and the file-name suffix `_SYNTHETIC`.
