## Findings to pass on (not fixed)

1. **QC and NC-1 (F7).** `qc_pass` is a precomputed column of `samsung_checkups.csv` made by `flag_outliers`, which is causal (verified by test): window labels, the anchor and training sides cannot depend on post-window labels through it. A garbage value after the window can be flagged and dropped, which changes the retained record length n, hence the forecast set of any cell and the D025 window `min(k, n - 2)` of a short cell. NC-1 scrambles after `build_data`, so it holds the retained set fixed by construction; a scramble upstream of the QC cannot be bit-identical for capped cells. This is the dependence red-team M4 named; it needs a sentence in section 10 (designer), not code.
2. **Row (i) reverse-S level.** `lab_stratified_tiers` tests reverse S for the secondary contrasts at `alpha` (0.025), while rows (ii)-(iv) and the primary use the slot level. Conservative direction for P1 and K2 (same level as the primary); for the secondary tests it can call reverse S at a looser level than the slot's. Not in the D033 list; left as is.
3. `permute_stress` at k = 0 still takes the design throughput from the permuted stress vector (a k = 0 window has no logged rate by design), so NC-2 moves the throughput of k = 0 predictions only; the P chain does not use k = 0.
4. `run_v4` without `sources` (direct callers, tests) prints the primary numbers under a lowered tier; only `run_v4_full` (the path of `run_stats_v4`) supplies sources.
